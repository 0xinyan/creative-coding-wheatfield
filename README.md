# Flowing Wheatfield

**IDEA9103 Creative Coding · Three Iterations of My User Input Work**

This repository documents three iterations of my contribution to our interactive p5.js reinterpretation of Vincent van Gogh’s *Wheatfield with a Reaper*. The first two versions are my input prototypes. The third brings my work together with my teammates’ Time and Noise mechanics and is our final group submission.

| Version | What changed |
| --- | --- |
| [Version 1 · Mouse Interaction Prototype](./IDEA9103_Flowing_Wheatfield/) | I used mouse position and movement to make nearby wheat sway while preserving the original brushstrokes. |
| [Version 2 · Pixel Sky and Click-to-Harvest](./IDEA9103_Flowing_Wheatfieldf_stage2/IDEA9103_Flowing_Wheatfield/) | I added a pixel sky, retained the tree’s painted texture, and made the reaper swing his sickle when clicked. |
| [Version 3 · Final Group Submission](./IDEA9103_Flowing_Wheatfield_version%203/) | I integrated the group’s Time and Noise modules, added X-key pause and daylight/sunset switching, and optimised rendering. |

Open the folder for the version you want to view and run its `index.html` with Live Server. Keep an internet connection available to load p5.js.

The [final project README](./IDEA9103_Flowing_Wheatfield_version%203/README.md) explains the controls, code structure, team contributions and AI assistance.
