# Wheatfield — Independent Noise Study 02

这是你的 Perlin noise + randomness 独立中间进阶版。参考组员的视觉呈现：
原画油画纹理、金黄麦田和深色页面。没有使用、修改或载入组员的 Wheat.js，
没有实现鼠标输入、鸟群或时间事件 mechanic。

## 运行

解压后，双击 preview.html，可离线运行。全部文件需保留在同一文件夹。
日常开发可用 VS Code Live Server 打开 index.html。
两个入口共用同一份 noise-mechanic.js 和 sketch.js。
preview.html 仅额外内嵌一份原画，以避开直接打开本地图片时的浏览器限制。
更换原画时，也要更新 preview.html 中的内嵌图片；它不会自动同步 assets。

无需鼠标操作。等待约两秒让风渐入，再观察麦田纹理的小幅流动。

## 独立实现方式

sketch.js 负责加载和绘制完整原画，调用你的 NoiseField。
noise-mechanic.js 新写 NoiseField 类，用 32×16 的局部图像片段表现风。
目的矩形固定，noise 控制从原画取样的水平位置，形成轻微的纹理流动。
random 只在初始化时设置每块的响应程度与采样偏移；每帧不会重新随机。
相邻位置使用相近 noise 采样，产生有关联的运动。另一个较慢的 noise
控制风力强弱。前景受风较明显，远处较轻，启动时逐渐加强。

这与前一版逐根麦秆的画法不同，但保留了“固定随机差异 + 连续 noise
变化”的核心学习内容。视觉上沿用油画本身的纹理，更接近组员的画面。

## 你可以改的参数

在 noise-mechanic.js 中：

- strength = 5：水平位移强度。可先比较 3、5、7，避免位移太大。
- speed = 0.006：风变化速度，可比较 0.004 和 0.008。
- patchWidth = 32 / patchHeight = 16：局部片段尺寸，可作为下一版实验。
- response 的 random 范围：控制不同区域的固定响应差异。
